# Libre AI Execution Sandbox

## Usage visé

Fournir une frontière d’exécution qui impose à un worker les limites d’un profil explicitement admis et consigne le résultat réellement observé. Missions décrit le travail demandé et Mission Control le coordonne ; aucun ne remplace les contrôles du système d’exploitation nécessaires au confinement.

## Candidats existants et limites

Les anciennes sources Harness et des candidats de qualification locale délimités existent. Leurs limites exactes de plateforme et de révision doivent être préservées ; ni un ancien README ni une campagne isolée réussie n’admettent tous les profils d’exécution ou l’outil distribué final. Ce candidat documentaire n’admet aucun environnement isolé généralement disponible ou garantie universelle de confinement.

## Contrats proposés

Une demande d’exécution précise le profil visé et l’autorité permettant ses effets autorisés. Un résultat distingue le refus avant lancement, l’achèvement réussi, l’interruption et les preuves indisponibles. Des prérequis manquants doivent provoquer un refus plutôt qu’une exécution moins protégée. Une attestation rapporte les observations dans son périmètre qualifié ; elle ne donne pas une permission d’agir.

## Critères d’activation

Qualifier la plateforme, la chaîne d’outils et le profil exacts avec des tests indépendants de succès, de refus et de confinement, ainsi que les contrôles de couverture par fichier revus. Le comportement Linux retenu interrompt un worker lorsque son canal se ferme ; cela peut refuser un programme normal et doit rester documenté et testé. Vérifier le nettoyage et l’intégration avec le consommateur réel sans supposer qu’une décision d’autorisation fournit le confinement.

La qualification suit le périmètre réellement retenu. Un module candidat peut être admis séparément avec son consommateur et ses preuves ; les critères de parcours complet s’appliquent au produit ou à l’intégration correspondante. Un noyau pur ne nécessite pas une intégration de worker, de base de données ou de relais hors de son périmètre. Ni l’admission d’un module ni l’existence documentaire de ce dépôt ne nécessitent un parcours Missions complet.
